Getting started, then a place to learn formulas and actions without touching yours.

## How it works
- Three first steps, each with the button that takes it, and answers to common questions.
- The playground: made-up signals (a value a minute) and variables. Try an operator and watch
  what it reads minute by minute, type an expression, or run an action on the variables.
- How programs work, as slides of the app with a few points each.
- Every function and action, found as you type.

## Limits
- A slide whose screenshot is missing shows a placeholder naming it.
