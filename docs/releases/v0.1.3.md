# Proki v0.1.3

Proki now sits in your menu bar with a panel of its own, can be paused, and lets you see exactly what drives each automation: what sets a value, what reads it, and where. An AI assistant can now build automations for you from everyday words.

## ✨ Highlights

- **A tray panel.** Click Proki's icon for your focus score, a new or running focus session, a new note, Settings and Quit. Right-click still opens the menu.
- **Pause Proki.** Its automations stop until you turn it back on, and nothing recorded meanwhile is replayed later. The pause holds through a restart.
- **Launch at login**, from the tray panel.
- **See what drives each automation.** Every input, signal, variable and rule opens one dialog with its type, its value now and its fields. It also shows two tables:
  - **Written by**, by how: its formula (`expr`), an automation (`auto`), you (`user`), or Proki itself (`proki`).
  - **Read by:** the automations' transitions and actions, rules, signals, variables and the app.

  Click a row for the detail. A place in an automation opens right there, highlighted, from any page.
- **Build automations by talking to your assistant.** The new `proki-automation` skill teaches Claude Code, Codex, Cursor and others to create, change, explain and troubleshoot your automations ("remind me to stretch every hour, but not in calls"):
  ```bash
  npx skills add Combi2k2/proki --skill proki-automation
  ```

## 🎛️ Automations

- A state opens in a dialog over the window, and asks before losing a change you haven't saved.
- What your automations can use is in a **Resources** bubble at the window's corner, on every page. The Global scope lists the same resources wherever you open it, and inputs sit under Global like everything else.
- Change a name, a description, a type, a formula or a starting value by clicking it. A dotted underline shows what can be changed.
- Set a variable's value yourself from its `user` row. An automation that writes it later replaces it.
- A record's fields (a task's, a note's) open the same kind of dialog. Their sources sit in a table, and the first source with a value wins.
- Lists and records show as `[…]` and `{…}`. Click one to see what's inside.
- The automations graph fits itself to the window until you move it. A box opens from the keyboard (Enter or Space), and a double-click pins it without opening it.

## ⚙️ Settings and the app

- **How often Proki looks**, from 1 to 60 seconds, set in Settings. Shorter answers sooner and works your computer harder.
- **Contribute is now Support.** It links to [buy me a coffee](https://buymeacoffee.com/combi2k2), and a suggestion can carry up to three pictures (PNG, JPEG, WebP or GIF, 2 MB each).
- Pages use the window's width as their content needs. Reading pages keep a comfortable column, and Tables takes all the room its columns want.
- The app is called Proki everywhere you see its name.
- In Tables, a "no" shows as a red cross.

## 🐛 Fixes

- The tray panel opens under its icon on any screen, including after a monitor is plugged in or out.
- The welcome screen no longer gets stuck on "Getting things ready".
- Ports that can't be used no longer stop Proki from starting. It falls back to the usual ones and tells you why.
- LLM requests work with services that accept only one system message. A service error on a structured answer falls back to asking in plain words.

## 🔒 Security

- Proki's message bus now accepts only programs holding the tools' token. Before, any program on your computer could publish on it: quit Proki, change your tasks and notes, or answer its questions. The token is read from a file only you can read, never from the command line.
- The token is compared in constant time.

## 🛠️ For builders

- New MCP tools:
  - `links`: what writes a name and what reads it, across every automation.
  - `cycle`: how often Proki looks, read or set.
- `suggest` takes `pictures`.
- A NATS server you already run without a token still accepts Proki.
- The installers are built from pinned, hash-checked packages. The macOS app is signed ad hoc and verified as the build ends.
- CI runs the tests on macOS and Windows before building the installers.

## ⚠️ Known limits

- The app isn't signed with a developer ID. On macOS, run `xattr -cr /Applications/Proki.app` once. On Windows, choose **More info → Run anyway**.
- Windows isn't tested on a real machine yet, and there's no Linux installer.
- A value you set yourself holds only until an automation writes it: the last write wins.
